1. Aplikacja z jednym CheckBoxem - Wybór opcji

Aplikacja z jednym CheckBox, która wyświetla komunikat, gdy opcja jest zaznaczona.

<Window x:Class="CheckBoxApp1.MainWindow"
        xmlns="http://schemas.microsoft.com/winfx/2006/xaml/presentation"
        xmlns:x="http://schemas.microsoft.com/winfx/2006/xaml"
        Title="CheckBox Example 1" Height="200" Width="300">
    <Grid>
        <CheckBox Name="checkBox" Content="Zgadzam się" VerticalAlignment="Center" HorizontalAlignment="Center"/>
        <Button Content="Potwierdź" HorizontalAlignment="Center" VerticalAlignment="Bottom" Click="Button_Click"/>
    </Grid>
</Window>

W C#: --------------------------------------------------------------------------------------------------------------------------------------------------------------------

private void Button_Click(object sender, RoutedEventArgs e)
{
    if (checkBox.IsChecked == true)
        MessageBox.Show("Zgodziłeś się!");
    else
        MessageBox.Show("Nie zgodziłeś się.");
}

2. Aplikacja z wieloma CheckBoxami - Wybór wielu opcji

Aplikacja z kilkoma CheckBoxami do wyboru wielu opcji.

<Window x:Class="CheckBoxApp2.MainWindow"
        xmlns="http://schemas.microsoft.com/winfx/2006/xaml/presentation"
        xmlns:x="http://schemas.microsoft.com/winfx/2006/xaml"
        Title="CheckBox Example 2" Height="250" Width="300">
    <Grid>
        <CheckBox Name="checkBox1" Content="Opcja 1" Margin="10"/>
        <CheckBox Name="checkBox2" Content="Opcja 2" Margin="10"/>
        <CheckBox Name="checkBox3" Content="Opcja 3" Margin="10"/>
        <Button Content="Pokaż zaznaczone" HorizontalAlignment="Center" VerticalAlignment="Bottom" Click="Button_Click"/>
    </Grid>
</Window>

W C#: --------------------------------------------------------------------------------------------------------------------------------------------------------------------

private void Button_Click(object sender, RoutedEventArgs e)
{
    string selectedOptions = "Zaznaczone opcje:\n";
    
    if (checkBox1.IsChecked == true)
        selectedOptions += "Opcja 1\n";
    if (checkBox2.IsChecked == true)
        selectedOptions += "Opcja 2\n";
    if (checkBox3.IsChecked == true)
        selectedOptions += "Opcja 3\n";

    MessageBox.Show(selectedOptions);
}

3. Aplikacja z CheckBoxem do zmiany koloru tła

Aplikacja z CheckBoxem, który zmienia kolor tła okna.

<Window x:Class="CheckBoxApp3.MainWindow"
        xmlns="http://schemas.microsoft.com/winfx/2006/xaml/presentation"
        xmlns:x="http://schemas.microsoft.com/winfx/2006/xaml"
        Title="CheckBox Example 3" Height="200" Width="300">
    <Grid>
        <CheckBox Name="checkBox" Content="Zmień kolor tła" VerticalAlignment="Center" HorizontalAlignment="Center"/>
    </Grid>
</Window>

W C#: --------------------------------------------------------------------------------------------------------------------------------------------------------------------

private void checkBox_Checked(object sender, RoutedEventArgs e)
{
    if (checkBox.IsChecked == true)
        this.Background = new SolidColorBrush(Colors.LightBlue);
    else
        this.Background = new SolidColorBrush(Colors.White);
}

4. Aplikacja z CheckBoxem do włączenia i wyłączenia tekstu

Aplikacja z CheckBoxem, który włącza i wyłącza widoczność tekstu.

<Window x:Class="CheckBoxApp4.MainWindow"
        xmlns="http://schemas.microsoft.com/winfx/2006/xaml/presentation"
        xmlns:x="http://schemas.microsoft.com/winfx/2006/xaml"
        Title="CheckBox Example 4" Height="200" Width="300">
    <Grid>
        <CheckBox Name="checkBox" Content="Pokaż tekst" VerticalAlignment="Top" Margin="10"/>
        <TextBlock Name="textBlock" HorizontalAlignment="Center" VerticalAlignment="Center" Text="Witaj, świecie!" Visibility="Collapsed"/>
    </Grid>
</Window>

W C#: --------------------------------------------------------------------------------------------------------------------------------------------------------------------

private void checkBox_Checked(object sender, RoutedEventArgs e)
{
    textBlock.Visibility = Visibility.Visible;
}

private void checkBox_Unchecked(object sender, RoutedEventArgs e)
{
    textBlock.Visibility = Visibility.Collapsed;
}

5. Aplikacja z CheckBoxem i Sliderem (Zmiana wartości z CheckBox)

Aplikacja z CheckBoxem i Sliderem, w której zaznaczenie CheckBoxa zmienia wartość Sliddera.

<Window x:Class="CheckBoxApp5.MainWindow"
        xmlns="http://schemas.microsoft.com/winfx/2006/xaml/presentation"
        xmlns:x="http://schemas.microsoft.com/winfx/2006/xaml"
        Title="CheckBox Example 5" Height="200" Width="300">
    <Grid>
        <CheckBox Name="checkBox" Content="Włącz zmianę wartości" VerticalAlignment="Top" Margin="10"/>
        <Slider Name="slider" VerticalAlignment="Center" Width="200"/>
    </Grid>
</Window>

W C#: --------------------------------------------------------------------------------------------------------------------------------------------------------------------

private void checkBox_Checked(object sender, RoutedEventArgs e)
{
    slider.IsEnabled = true;
}

private void checkBox_Unchecked(object sender, RoutedEventArgs e)
{
    slider.IsEnabled = false;
}
